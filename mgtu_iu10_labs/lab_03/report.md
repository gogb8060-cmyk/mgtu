## 2. Словесная постановка задачи

### 2.1. Суть задачи
Реализуется структура данных «линейный односвязный список» — конечный упорядоченный набор узлов, связанных ссылками. В отличие от массива, элементы списка не лежат в непрерывной области памяти: порядок определяется ссылками `next` между узлами. Это обеспечивает динамическое изменение размера без дорогостоящего копирования и сдвига элементов, но ценой потери быстрого доступа по индексу.

Работа выполняется итеративно: каждая из 6 версий списка добавляет одну новую возможность (указатель на хвост, поиск и удаление, счётчик, итератор, методы `reverse`/`sort`, индивидуальное задание), что позволяет проследить эволюцию структуры данных от минимальной рабочей реализации до полнофункционального контейнера.

### 2.2. Анализ переменных
- `Node` — узел списка, содержит поле `data` (полезные данные) и `next` (ссылка на следующий узел);
- `head` — указатель на первый узел списка (голова), точка входа для обхода;
- `tail` — указатель на последний узел списка (хвост), ускоряет добавление в конец;
- `_length` — счётчик элементов, обеспечивает получение длины за O(1);
- `prev`, `current`, `next_node` — вспомогательные указатели при обходе и модификации списка;
- `counts` — словарь для подсчёта частоты элементов (в индивидуальном задании).

### 2.3. Ограничения и условия эксперимента
- Список реализуется без использования встроенных структур Python (`list`, `deque`) внутри узлов — только через узлы и ссылки.
- Сортировка выполняется **на месте** — без создания нового списка, переставляются только значения в узлах.
- Разворот списка выполняется без выделения дополнительной памяти (O(1) по памяти).
- Индивидуальное задание требует двух проходов по списку: первый — подсчёт частот, второй — удаление.
- Итератор реализован через явный протокол `__iter__`/`__next__`, чтобы продемонстрировать механизм цикла по коллекции.

### 2.4. Условия разрешимости
- Все операции корректно обрабатывают пустой список (`head is None`).
- `reverse` работает для списка любой длины, включая список из одного элемента (в этом случае список не изменяется).
- `sort` использует метод пузырька, поэтому гарантированно завершается для любого конечного списка.
- Индивидуальное задание: если элемент встречается ровно 2 раза — он остаётся; если 1 раз — тоже остаётся; если 3 и более — удаляется.

### 2.5. Ожидаемые результаты
- Базовые операции (добавление в начало/конец, удаление, поиск) работают корректно и имеют ожидаемую асимптотику.
- `reverse` разворачивает список за один проход, O(n) по времени, O(1) по памяти.
- `sort` сортирует список на месте за O(n²) (метод пузырька).
- Индивидуальное задание корректно удаляет только те элементы, которые встречаются строго более 2 раз.
- Итератор позволяет использовать список в цикле `for x in list:` и функции `len()`.

## 3. Теоретический анализ временной сложности

| Операция | Односвязный список (без tail) | Односвязный список (с tail) | Обоснование |
| --- | :---: | :---: | --- |
| Поиск элемента | O(n) | O(n) | Требуется последовательный проход от головы |
| Вставка в начало | O(1) | O(1) | Переназначается только `head` |
| Вставка в конец | O(n) | O(1) | С `tail` не нужно идти до последнего узла |
| Удаление из начала | O(1) | O(1) | `head` переназначается на второй узел |
| Удаление из конца | O(n) | O(n) | Нужно найти предпоследний узел (ссылки однонаправлены) |
| Доступ по индексу | O(n) | O(n) | Последовательный проход |
| `reverse` | O(n) | O(n) | Один проход с перестановкой ссылок |
| `sort` (пузырёк) | O(n²) | O(n²) | Два вложенных прохода |
| Индив. задание | O(n) | O(n) | Два линейных прохода (подсчёт + удаление) |

**Сравнение с массивом.** Главное преимущество списка — эффективные вставки/удаления в начале за O(1) без сдвига элементов. Недостаток — невозможность быстрого доступа по индексу (O(n) вместо O(1) у массива) и дополнительные затраты памяти на хранение ссылок. Также узлы списка разбросаны в памяти, что снижает кэш-дружественность по сравнению с массивом.

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None


# ============ ЗАДАНИЕ 1: 6 версий списка ============

# Версия 1: ручное связывание узлов
print("=== Задание 1: Версия 1 (ручное связывание) ===")
head = Node(1)
head.next = Node(2)
head.next.next = Node(3)

current = head
while current:
    print(current.data, end=" -> ")
    current = current.next
print("None\n")


# Версия 2: базовый контейнер
class LinkedListV2:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            return
        last = self.head
        while last.next:
            last = last.next
        last.next = new_node

    def display(self):
        current = self.head
        elements = []
        while current:
            elements.append(str(current.data))
            current = current.next
        print(" -> ".join(elements) + " -> None")


print("=== Задание 1: Версия 2 (базовый контейнер) ===")
ll2 = LinkedListV2()
ll2.append(10)
ll2.append(20)
ll2.display()
print()


# Версия 3: добавляем tail и prepend
class LinkedListV3(LinkedListV2):
    def __init__(self):
        super().__init__()
        self.tail = None

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            self.tail = new_node
            return
        self.tail.next = new_node
        self.tail = new_node

    def prepend(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node
        if not self.tail:
            self.tail = new_node


print("=== Задание 1: Версия 3 (+ tail и prepend) ===")
ll3 = LinkedListV3()
ll3.append(10)
ll3.append(20)
ll3.prepend(5)
ll3.display()
print()


# Версия 4: поиск и удаление
class LinkedListV4(LinkedListV3):
    def search(self, key):
        current = self.head
        while current:
            if current.data == key:
                return True
            current = current.next
        return False

    def delete(self, key):
        current = self.head
        previous = None
        while current:
            if current.data == key:
                if previous:
                    previous.next = current.next
                    if current == self.tail:
                        self.tail = previous
                else:
                    self.head = current.next
                    if not self.head:
                        self.tail = None
                return True
            previous = current
            current = current.next
        return False

ll4 = LinkedListV4()
ll4.append(10)
ll4.append(20)
ll4.append(30)
print(f"Поиск 20: {ll4.search(20)}")
print(f"Поиск 99: {ll4.search(99)}")
ll4.delete(20)
ll4.display()
print()


# Версия 5: итератор и счётчик (задание 5)
class LinkedListV5(LinkedListV4):
    def __init__(self):
        super().__init__()
        self._length = 0

    def append(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            self.tail = new_node
        else:
            self.tail.next = new_node
            self.tail = new_node
        self._length += 1

    def prepend(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node
        if not self.tail:
            self.tail = new_node
        self._length += 1

    def delete(self, key):
        current = self.head
        previous = None
        while current:
            if current.data == key:
                if previous:
                    previous.next = current.next
                    if current == self.tail:
                        self.tail = previous
                else:
                    self.head = current.next
                    if not self.head:
                        self.tail = None
                self._length -= 1
                return True
            previous = current
            current = current.next
        return False

    def __len__(self):
        return self._length

    def __iter__(self):
        self._current = self.head
        return self

    def __next__(self):
        if self._current is None:
            raise StopIteration
        data = self._current.data
        self._current = self._current.next
        return data


print("=== Задание 5: Версия 5 (итератор и len) ===")
ll5 = LinkedListV5()
ll5.append("Python")
ll5.append("JS")
ll5.append("C++")
print(f"Длина списка: {len(ll5)}")
print("Обход через for:")
for lang in ll5:
    print(f"  {lang}")
print()


# Версия 6: финальная (reverse, sort, индив. задание)
class LinkedListV6(LinkedListV5):
    def __repr__(self):
        elements = [str(x) for x in self]
        return " -> ".join(elements) + " -> None"

    def __getitem__(self, index):
        if index < 0:
            index = self._length + index
        if index < 0 or index >= self._length:
            raise IndexError("Index out of range")
        current = self.head
        for _ in range(index):
            current = current.next
        return current.data

    def reverse(self):
        if not self.head or not self.head.next:
            return
        prev = None
        current = self.head
        self.tail = current
        while current:
            next_node = current.next
            current.next = prev
            prev = current
            current = next_node
        self.head = prev

    def sort(self):
        if not self.head or not self.head.next:
            return
        swapped = True
        while swapped:
            swapped = False
            current = self.head
            while current.next:
                if current.data > current.next.data:
                    current.data, current.next.data = current.next.data, current.data
                    swapped = True
                current = current.next

    def remove_elements_more_than_two(self):
        if not self.head:
            return
        counts = {}
        current = self.head
        while current:
            if current.data in counts:
                counts[current.data] += 1
            else:
                counts[current.data] = 1
            current = current.next

        previous = None
        current = self.head
        new_tail = None
        while current:
            if counts[current.data] > 2:
                if previous:
                    previous.next = current.next
                else:
                    self.head = current.next
                self._length -= 1
            else:
                previous = current
                new_tail = current
            current = current.next
        self.tail = new_tail

### 5.2. Анализ результатов

**Версии 1–5 (эволюция структуры).** Каждая версия добавляет одну новую возможность:
- V1 демонстрирует «механику» списка на уровне узлов — видно, как ссылки `next` образуют цепочку.
- V2 вводит класс-контейнер, скрывающий работу с узлами.
- V3 добавляет `tail`, что ускоряет `append` с O(n) до O(1).
- V4 добавляет поиск и удаление с корректным обновлением `tail` при удалении последнего элемента.
- V5 добавляет итератор и счётчик — список становится «родным» для Python: работают `for x in list` и `len()`.

**Reverse (задание 2).** После разворота порядок элементов изменился на обратный: `4, 3, 2, 1`. Алгоритм отработал за один проход, дополнительная память не выделялась (только три указателя `prev`, `current`, `next_node`). Сложность — O(n) по времени, O(1) по памяти.

**Sort (задание 3).** После сортировки методом пузырька список принял вид `1, 2, 4, 5, 8`. Сортировка выполнена на месте — менялись только значения в узлах, структура списка (ссылки) не изменялась. Сложность — O(n²).

**Индивидуальное задание (вариант 24).** Элемент `2` встречался 3 раза (>2) — удалён. Элемент `3` встречался 2 раза (не более 2) — остался. Элементы `1` и `4` встречались по 1 разу — остались. Итоговый список `1, 3, 3, 4` соответствует условию задания. Длина уменьшилась с 7 до 4.

**Доступ по индексу.** Метод `__getitem__` корректно обрабатывает как положительные (`ll[2]`), так и отрицательные (`ll[-1]`) индексы. Сложность O(n) — необходимо пройти по цепочке от головы.
